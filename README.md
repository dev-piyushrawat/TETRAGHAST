# TETRAGHAST 👻

**Four Chapters. One Way Out.**

TETRAGHAST is a first-person psychological survival horror game developed by Piyush Rawat.

Explore a mysterious facility, solve environmental puzzles, survive terrifying encounters, and find your way out.

## 🎮 Play TETRAGHAST

**Windows PC Edition — Available on itch.io**

https://dev-piyushrawat.itch.io/tetraghast

## 🕹️ Features

- Four interconnected horror chapters
- Four unique hostile entities
- First-person exploration and survival gameplay
- Environmental puzzles and interactive objects
- Atmospheric horror soundtracks
- Save & Continue
- Unlockable Entity Archive
- Custom graphics and audio settings

## 🏚️ Chapters

1. The Awakening
2. The Basement
3. The Poolrooms
4. Exit Protocol

## 💻 Platform

Windows PC
